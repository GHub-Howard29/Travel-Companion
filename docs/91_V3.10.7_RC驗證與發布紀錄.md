## 1. RC 範圍

- DEV 安全：非 loopback Supabase URL 硬阻擋，避免下載專案的人以 DEV 測試帳號誤連正式資料庫。
- 天氣來源：保存 Open-Meteo 實際查詢來源網址、座標、日期與時區；舊快取缺少必要欄位時不猜測地點、不連到首頁。
- 天氣穩定性：要求 lease release RPC 明確回傳 true，修正同一 token 的過期 lease 回寫與失敗清理。
- UI：修正天氣來源選單在窄螢幕超出 viewport 的問題，保留 Open-Meteo 與 CC BY 4.0 標示。
- 安全文件：記錄 Supabase Advisor 既存 RLS、SECURITY DEFINER、pg_net 與 Auth 密碼防護提醒，留待後續安全掃描再審查；本 RC 不直接修改這些既存設定。
