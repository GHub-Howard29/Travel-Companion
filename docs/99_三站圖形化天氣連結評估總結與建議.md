# 三站圖形化天氣連結評估總結與建議

> 評估日期：2026-10-20
> 狀態：**2026-10-20 依使用者指示終止本輪圖形化天氣方案評估；本文件為終止時的彙整與封存紀錄，不再推進候選驗證或整合。**
> 範圍：只評估 Travel-Companion 行程天氣卡片的外部圖形化天氣連結。終止前未修改應用程式、資料庫、migration、正式設定或部署；本文件與相關天氣文件已整理後提交。

## 一、最終建議

**終止時的比較結果：Drizz.li（7.5/10，條件式最高分）＞ meteoblue（5.0/10，暫不採用）＞ Weather.com（4.0/10，暫不採用）。這只是本輪研究的比較紀錄，不代表批准採用或後續優先開發。使用者已要求先終止評估，因此不再追蹤剩餘驗證、不開始整合，現有 Open-Meteo 來源連結維持不變。**

- **Drizz.li：本輪分數最高，但未獲採用核准。** 官方專案公開，現有東京／京都具名頁可呈現逐日與逐時預報；士林 ID-backed 頁雖初始 HTTP 回應為 404，但 SPA fallback 後可渲染地名、逐日卡片與逐時資料表，圖表視覺仍部分驗證。Open-Meteo Geocoding 免費 API 僅允許非商業用途；Travel-Companion 是否符合該分類未確認。依使用者指示，終止時不再進行後續驗證。
- **meteoblue：具名頁技術能力存在，但目前不採用。** 京都頁可用，台北士林正確頁未找到，同名 Shilin 誤配風險已實證；公開條款對 referral／外部連結設有標誌、通知或事先許可條件，須取得官方書面確認。API 的商業使用協議與費用也未明。
- **Weather.com：城市／行政區頁可用，但連結生成與授權風險最高。** 士林與京都頁可顯示逐時及 10 日預報；直接拼接地名的常見 URL 失敗，座標 URL 會重導向行政區頁，POI／同名地點的可靠配對未證實。官方 API 僅有受資格限制的 30 天試用或 Standard 年約 USD 500／月，依硬性條件排除。網站條款的個人非商業授權亦未能明確支持本產品情境。

## 三、共同硬性條件判定

1. **固定費用或僅限期試用方案排除。** Weather.com API 不符合；meteoblue 的商業 API 協議與費用尚未查明，不能當成符合；Open-Meteo 商業 Geocoding 方案也不列入候選。
2. **免費網站不等於免費整合授權。** 必須分開確認一般瀏覽、外部深層連結、API、自動化及商業用途。
3. **不得用 HTML 擷取或猜測 URL 規則。** 對沒有官方支持的地名 URL 產生方式，不以爬取網站、內部 API 或搜尋第一筆作為替代。
4. **配對規則維持已定案條件。** 對 Drizz.li 使用原始座標與候選座標計算直線距離，選最近且距離 ≤1,000 m 的候選；若無結果、查詢失敗、最近候選超過 1,000 m 或只有座標頁，保留 Open-Meteo 來源連結。不另外增加名稱、國家或行政區作為必要門檻。
5. **Open-Meteo source_url 不可被外部網站 URL 覆寫。** 若日後採用 Drizz.li，需獨立保存連結／配對資訊，並定義座標更新、Place ID 變更與座標快取到期時的失效規則。
6. **在授權釐清前不實作。** 不修改程式、schema、migration、Edge Function、排程或正式環境。

## 四、瀏覽器工具問題與替代驗證

2026-10-20 測試期間，Open Browser Use 的 tabs、open_tab、info 等呼叫持續回報內部錯誤；Open Computer Use 能讀取 Chrome 視窗狀態，但 set_value／press_key 也發生內部錯誤。沒有重啟 MCP、改設定或干擾使用者既有 Chrome 工作。

已採取替代方式：
- 透過公開頁面擷取直接確認 Drizz.li 東京頁 HTTP 200 並有逐日／逐時內容；士林及京都路徑的初始 HTTP 狀態雖為 404，但頁面文字有 SPA fallback 內容及預報資料，不能只看 HTTP 狀態判斷成功或失敗。
- 既有 Drizz.li 隔離 Chrome headless 紀錄已確認士林／京都地名與預報資料可渲染；Loading charts... 仍存在，因此圖表視覺完整性只部分驗證。
- Weather.com 京都與士林區具名頁 HTTP 200，內容包含逐時預報與 10 日預報；這是公開頁內容檢查，不是使用者 Chrome profile 的互動測試。
- meteoblue 京都及同名 Shilin 頁面的 HTTP／內容證據已記錄；互動式瀏覽器矩陣仍未完成。
- Open-Meteo Geocoding 直接查詢 Shilin, Taiwan 回傳台灣士林候選；Shilin Night Market, Taipei 未回傳候選，符合既有景點查詢 fallback 判斷。

因此，本輪已能形成**產品層面的暫定去留結論**，但不能宣稱三站已通過完整瀏覽器驗收。工具問題已以官方文件與公開頁面擷取補足部分證據，Chrome 操作本身仍是未解的工具限制。

## 五、終止時未解項目（封存，不是目前待辦）

以下問題在終止評估時仍未解決，僅供未來若使用者重新啟動此議題時參考；目前不執行、不追蹤，也不代表已核准任何方案：

- Travel-Companion 是否符合 Open-Meteo Geocoding API 的非商業免費使用定義。
- Drizz.li 士林 ID-backed 頁面的圖表完整性，以及一般瀏覽器／手機新分頁重開驗證。
- meteoblue 的 referral／商業連結書面授權與台北士林精確地點頁。
- Weather.com 純外部連結的條款許可、UI 搜尋及同名地點選取規則。

終止決策：不再進行以上驗證，不開始整合，不修改程式、資料庫或部署；現有 Open-Meteo 來源連結維持原狀。
