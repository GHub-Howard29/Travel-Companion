## 1. 發布範圍

修正 Android PWA 更新流程在 Service Worker 已啟用但目前頁面尚未由新版 Worker 控制時，錯誤判定 handoff 失敗並造成更新提示重複的問題。

本次修改範圍：
- src/hooks/useAppUpdate.ts：以 expected Worker 同時符合 activated、registration.active 與 navigator.serviceWorker.controller 條件確認接管；waiting Worker 僅送出一次 SKIP_WAITING；接管後寫入 pending target version 並只 reload 一次；新 document 以 APP_VERSION 核對目標版本；reload guard 阻止循環。
- src/components/UpdatePrompt.tsx：調整更新切換中的提示文案與逾時／失敗訊息。
- 三支既有 PWA regression 腳本：同步驗證新版 handoff 與新頁面版本確認，並移除對前一版固定版號的硬編碼，改驗證版本格式及 metadata 一致性。
- docs/110_正式PWA網路行為自動鑑測與AI診斷計畫.md：追加本次實作與驗證紀錄。

不涉及 Supabase migration、正式資料庫寫入、Edge Function 或 Secrets。
