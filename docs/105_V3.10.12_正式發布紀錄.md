# V3.10.12 正式發布紀錄

> 狀態：V3.10.12 已完成 develop／main 推送、annotated tag 與 GitHub Pages 部署；公開資產 smoke 通過。人工／真機驗收債依本文件保留為發布後待驗。

> 發布日期：2026-11-01。

## 發布範圍

- 每日行程卡片冷啟動／前景／revision 路徑強制向雲端重新驗證；安全合併本機與雲端快照，離線 pending／衝突不被無條件覆蓋。
- 以 base／local／cloud 三方比較處理不同卡片／欄位、刪除、搬移及排序衝突；逐筆選擇後再次取得最新雲端快照並以 optimistic-lock 寫入、回讀確認。
- 每日行程卡片編輯租約：只有已登入、具編輯權、非歷史唯讀且在線時才載入租約服務；編輯前 claim、定時 heartbeat、失效時 fail-closed，保存前再次檢查。
- 共同清單、私人清單、其他資訊、外幣換算的背景讀取不顯示短暫「同步中」；使用者主動寫入仍保留操作回饋，離線／pending／失敗提示保留。
- 變更摘要背景刷新保留現有摘要，移除短暫「收到新的變更／正在更新最新統計」提示；revoked／conflict 關鍵狀態仍保留。
