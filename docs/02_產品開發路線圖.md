## 版本編號規則

採 `MAJOR.MINOR.PATCH`：

- `X`（Major）：產品世代、核心架構或資料模型發生大規模且不相容的改變。
- `Y`（Minor）：新增一項明確、可被使用者感知的主要功能，或進入新的產品功能階段。
- `Z`（Patch）：Bug 修正、小型 UI／體驗改善、效能調整、安全維護或既有功能補強。
- `FORCE_UPDATE` 與版本層級分開判斷；只有資料不相容、安全、RLS／schema、同步或舊快取有重大風險時才建議強制更新。

版本發布後不可回寫版號、migration 或版本歷史；若發現問題，使用新的向前修復版本。

### V3.4.8 PWA 更新重載流程修正（已發布）

- 問題原因：按下「馬上更新」後，程式在新版 Service Worker 完成頁面接管前先重新載入，接管事件又可能觸發第二次重載；因此可能再次載入舊版並重複顯示更新提示，Android PWA 也可能停留在純色啟動畫面。
- 修正更新流程，只在新版 Service Worker 的 `controlling` 事件發生後重新載入頁面。
- 加入單次重載與更新中防重入，避免接管事件、備援流程或重複點擊造成多次重載。
- Android WebView 保留延遲備援重載，但不再與正常接管流程競速。
- 本版不包含資料庫、RLS、migration 或 Trip 隱私變更，`FORCE_UPDATE = false`。
- 已由 Product Owner 完成合併、建立 `v3.4.8` tag 與部署。
- V3.4.7 升級當下仍由舊版更新程式執行，實機曾停留純色畫面一次；完全關閉後可正常進入 V3.4.8。新版防重載流程留待 V3.4.8 升級至下一版時驗證。

## 核定 Roadmap

### V3.5.0 Trip 公開／私人與 Guest 存取

這是一項新的主要產品能力，不是單純 UI 調整，因此使用 Minor 版號。以下內容必須作為同一完整安全版本發布，不得拆成 UI 版與資料庫版：

- Supabase `trips` 新增 `is_public boolean not null default false`；新 Trip 一律預設私人，既有雲端與靜態 Trip 在同一 migration 全數轉為私人。
- Trip 管理介面加入公開／私人設定；只有 `super_admin` 可查看及變更，私人轉公開前必須顯示個資警告並明確確認。
- Guest 只可讀公開 Trip；`trip_editor` 可讀公開 Trip 與自己負責的私人 Trip；`super_admin` 可讀全部 Trip。
- 以 RLS、REST API、Checklist、Other Info 附屬資料政策共同落實存取矩陣。
- 移除 `public/trips/` 靜態 Trip；公開與私人資料改走明確授權的不同載入流程。
- Offline First 快取依公開狀態、帳號與角色隔離；公開轉私人後，在下一次成功授權刷新時收斂失去權限者的舊快取。
- 候選前端、migration、RLS、靜態網址與快取驗證必須在同一維護窗口完成。
- 預設建議 `FORCE_UPDATE = true`，發布前由 Product Owner 最終確認。

### V3.5.1 Supabase Storage 附件權限

- 將 `expense-attachments` bucket 與 `storage.objects` 政策納入可版本控制的 migration。
- 確認 bucket 為 private，並依 Trip 權限限制 INSERT、SELECT、UPDATE、DELETE。
- 驗證附件路徑中的 Trip ID，並評估簽名網址有效期限。
- 屬既有功能的安全補強，使用 Patch；是否強制更新依舊版相容與暴露風險決定。

### V3.5.2 Supabase 資料庫權限函式硬化

- 盤點 `SECURITY DEFINER`、固定安全 `search_path`、收斂公開執行權限。
- 確認 `public` schema 建立物件權限，執行 database advisors 並回歸所有主要資料權限。
- 屬資料庫安全維護，使用 Patch。

### V3.5.3 前端瀏覽器安全防護（暫定）

- 加入 Content Security Policy，檢查外部視窗、HTML 與使用者輸入網址的安全邊界。
- 評估 Referrer Policy、Permissions Policy 與 GitHub Pages 可提供的安全 Header。
- 回歸 OAuth、PWA、Service Worker、附件及 Excel 匯出。
- 屬前端安全維護，使用 Patch；開始前重新確認實際範圍與版號。

### V3.6.0 地點間預估移動資訊

- 在每日行程相鄰地點間顯示交通方式、預估時間與距離，支援開車、步行及大眾運輸。
- Trip Editor／Admin 查詢並儲存；Guest／User 只查看已儲存結果。
- 這是新的主要使用者功能，因此由原規劃 V3.5.0 調整為 V3.6.0。
- 完整規格見《15_V3.6.0_地點間預估移動資訊規格》。
