## 版本編號原則

- `MAJOR`：產品世代、核心架構或資料模型有大規模且不相容的變更。
- `MINOR`：新增使用者可感知的主要功能，或進入新的產品功能階段。
- `PATCH`：Bug 修正、小型 UI／體驗改善、效能調整、安全維護或既有功能補強。
- `forceUpdate` 與版本層級分開判斷；資料不相容、安全、RLS／schema、同步或舊快取有重大風險時才建議必要更新。
- 版本發布後不回寫版號、migration 或版本歷史；問題以新版本向前修復。

## 排程中版本

### V3.9.19 文案精簡與每日行程卡片排版

- 精簡每日行程標題、管理提示與時間預覽說明，保留完整「到達／離開」文字及既有農曆顯示設定。
- 每日標題採 `D{日序} · MM/DD（星期縮寫）`；時間預覽提示採「選擇起點，預覽後續時間」。
- 長說明預設最多顯示 3 行，完整內容不刪除；展開／收合與選配的其他資訊、查看地圖共用同一操作列。
- 有照片卡片保留上方圖片、時間、類型與標題，說明改由圖片區塊下方以完整卡片寬度開始排列。
- 擴大盤點登入提醒、功能使用說明、同步／離線提示、表單輔助文字與錯誤訊息；安全、權限、資料風險與授權來源不得因精簡而遺漏。
- 全站文案盤點、桌面及 390×844 行動版 UI 確認圖與施作內容已定案；RC 已完成並曾部署 3.9.19 候選版，正式發布流程因另一台電腦的 source／未提交變更尚待找回而暫停；本版內容維持凍結，不再追加功能。

### V3.9.20 其他資訊自訂子類別

- 新增 Trip 內的其他資訊子類別管理，可新增、改名、拖曳排序、顯示／隱藏與恢復預設。
- 主畫面沿用既有「其他資訊管理」文案作為入口，不新增「管理子類別」重複文案。
- 顯示中使用眼睛圖示、隱藏使用斜線眼睛；切換時立即顯示「已顯示／已隱藏」約 1 秒後消失，隱藏不刪除既有資料。
- 提供自動排列：每列最多 3 個、換行後由少字元到多字元優先、長名稱放不下就換行，不壓縮字寬；規則說明預設收合。
- 新 Trip 採「共同基底＋TripMode 差異」：每日行程、清單、其他資訊、帳本、換匯等維持共同設計；只有行程性質標示與「領隊導遊聯絡資訊／自駕租車資訊」依 `guided`／`selfGuided` 切換。
- 「其他資訊」只保留一套共同系統預設分類，不直接複製兩個受保護 seed 行程；「恢復預設」亦回到這套共同分類，且不得刪除自訂分類或既有資料。
- 建立後切換行程性質只切換 TripMode 專屬資訊，不自動覆蓋其他資訊、每日行程、帳本、換匯或其他共同資料。
- UI、互動與共同基底／差異性規則已於 2026-09-30 定案；目前只完成規格文件，尚未實作與驗證。完整規格見《[67_V3.9.20_其他資訊自訂子類別規格](67_V3.9.20_其他資訊自訂子類別規格.md)》。

### V3.9.21 排序後續時間重算與調整時間整合評估

- 原 V3.9.20 計畫，因插入其他資訊自訂子類別而順延為 V3.9.21。
- 待 V3.9.20 完成後才進入詳細討論與規格定案。
- 評估排序完成後產生後續時間預覽、只重查受影響相鄰路線、沿用有效快取及顯示可能使用的路線查詢額度。
- 重新評估既有「調整時間」入口是否保留、改名或與排序後預覽共用流程。
- 固定時間、停留時間、進位規則、航班／跨午夜／缺少地點等停止條件均尚未定案；本階段不得實作。完整討論紀錄見《[68_V3.9.21_排序後續時間重算評估紀錄](68_V3.9.21_排序後續時間重算評估紀錄.md)》。

### V3.10.1 驗證套件整併與建置效能基線

- 建立完整 build 中各驗證群組、TypeScript 與 Vite build 的耗時基線。
- 依領域整併驗證入口與失敗報告，但不縮減 release build 的完整發布驗證。
- V3.9.3 已在 `src/main.tsx`／`src/App.tsx` 建立 `tc_app_bootstrap_start` 與 `tc_app_bootstrap_duration` 總啟動量測；V3.10.1 不重複新增程式內量測埋點，僅量測驗證與建置流程耗時。
- 不包含功能、資料庫、Edge Function、正式環境、版本 metadata 或部署變更。

### V3.10.2 離線冷啟動剖析與定向改善

- 沿用 V3.9.3 既有的總啟動量測，在本機新增 Service Worker／navigation、session、Trip 快取、localStorage、IndexedDB 與首個可操作畫面的分段耗時量測，以找出離線冷啟動約 30 秒的瓶頸。
- 只在證據足夠時實作定向改善；不破壞 Offline First、墓碑、pending 與同步安全。
- 不重複 V3.6.5 的更新後載入改善或 V3.9.3 的冷啟動總埋點；量測資料維持本機 Console，不新增遠端 telemetry 或蒐集行程、帳目、Email 等資料。

### V3.10.3 零費用 Playwright 響應式 E2E 回歸基礎

- 只使用 loopback fixture 與本機瀏覽器／viewport 模擬，不使用 production、外部 API 或付費雲端實機。
- 優先覆蓋核心導覽、窄螢幕溢位、重要對話框與既有合成資料契約。
- 不以模擬取代 Android／iOS 實體裝置的 PWA、OAuth、相機、離線與跨裝置驗證。

### V3.10.4 照片功能模組化、型別邊界與按需載入

- 沿用既有 lazy loading 與 Excel 動態載入成果，不重複開發。
- 以現有照片搜尋、裁切、上傳與來源 metadata 的型別邊界為主，不擴張新圖庫來源。
