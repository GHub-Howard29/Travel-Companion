## 發布範圍

- Day 標題在國曆日期後顯示括號包住的離線農曆干支年、月與日，與國曆共用字體大小、字重與顏色。
- Day 1 使用淺藍底藍字；中間 Day 使用淺綠底綠字；最後一天使用淺紅底紅字。選取時仍維持對應淺色語意配色，單日行程以最後一天紅色規則為準。
- 新增純前端 `lunar-javascript` 依賴與 `npm run setup`，新開發環境可依 `package-lock.json` 重現所有套件。
