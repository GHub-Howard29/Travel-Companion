# V3.7.0 正式發布操作手冊

> 狀態：候選版已完成封版驗證，待 GitHub Pages 發布與正式站 smoke
>
> 建立日期：2026-09-08
>
> 發布政策：一般更新；`minimumSupportedVersion: 3.6.4`、`forceUpdate: false`

## 發布範圍

V3.7.0 新增 Day 行程管理中的單次「調整時間」模式。管理者選定起點與新離開時間後，系統以有效路線時間、30 分鐘到達時間進位及原停留時間建立預覽；只有確認「套用調整」才整批更新同日後續活動。

Day 標題同時改為 `Day N 行程探索 YYYY-MM-DD`。日期依 Trip 出發日以本地日曆日推算，無效日期安全隱藏。

## 發布前檢查

- `package.json`、`package-lock.json`、`src/config/appVersion.ts` 與 `public/app-version.json` 均為 `3.7.0`。
- `PREVIOUS_RELEASE_VERSION = "3.6.5"`，且 V3.6.5 已收錄在 `versionHistory.ts`。
- `minimumSupportedVersion = "3.6.4"`、`forceUpdate = false`、`IS_MANDATORY_RELEASE = false`。
- `npm run lint`、`npm run build`、時間調整專項驗證與瀏覽器安全驗證全部通過。
- 本版不含 Supabase schema、RLS、Edge Function 或資料轉換；不需 production migration 或 backup。

## 部署與確認

在 `main` 執行 `npm run deploy`。部署完成後確認正式 `app-version.json`、首頁引用的新版資產與正式站行程頁可正常載入；部署結束後切回 `develop`。

待補的人工驗證為桌面、Android PWA、iOS Safari／standalone 的時間調整模式，以及實際大眾運輸查詢、跨裝置競態與離線快取流程。不得將未執行項目記為通過。
