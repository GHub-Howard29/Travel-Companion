# V3.9.5／V3.9.4 合併發布候選紀錄

> 狀態：發布候選；尚未正式發布
>
> 候選日期：2026-09-18
>
> 版本政策：一般更新；`minimumSupportedVersion: 3.9.2`、`forceUpdate: false`

## 1. 合併版本決策

- V3.9.4 不建立獨立正式版本、tag 或部署；已完成的照片搜尋、自行上傳與裁切功能併入 V3.9.5 一次發布。
- 正式 App 版本直接由 V3.9.3 升為 V3.9.5；V3.9.4 保留為開發規格編號，不列入已發布版本歷史。
- V3.9.5 同時包含原 V3.9.4 與 V3.9.5 的全部已實作內容，文件仍分別保留需求、設計與驗收邊界。

## 2. 合併發布範圍

### 原 V3.9.4

- Commons 精確搜尋首批零候選時自動再查一批，保留續頁並限制每 session 請求、時間、檔案與候選累積量。
- 精確層耗盡後可手動載入一層已驗證相關分類的延伸候選；搜尋範圍改為純狀態提示。
- 正式照片來源只保留 Wikimedia Commons 與自行上傳；Pexels 不接入 App，Pixabay 永久取消。
- 自行上傳提供拍照與系統選檔入口、紅色侵權提醒、完整原圖 `100%`、最高 `250%`、同圖模糊背景、76×76 預覽及 640×640 WebP 儲存。

### 原 V3.9.5

- 航班卡片不建立、顯示、快取或使用前往下一張卡片的地面交通，儲存時清除既有區段資料。
- 每日行程到達、離開與時間調整輸入接受 `H:MM`、`HH:MM`、半形四碼、全形四碼及 IME 組字。

## 3. 發布候選驗證

- `npm run regression:local:full` 通過：本機 Supabase grants、管理者登入、Trip 載入、Edge 輸入防線、lint 與完整 build 均通過；未送出 Wikimedia 或 production 請求。
- `npm run build` 通過：版本政策、V3.9.0／V3.9.1／V3.9.3／V3.9.4 契約、App／Node TypeScript、production Vite、PWA 與瀏覽器安全檢查均通過。
- 依 Product Owner 2026-09-18 決定，本次不執行互動驗證。實際 Storage 上傳／刪除、桌面／390×844、相機／相簿／系統雲端選檔、鍵盤焦點及跨裝置重載維持已接受的發布殘餘風險。

## 4. 發布邊界

- 尚未執行 production Edge Function 部署、`develop` 合併 `main`、push、annotated tag `v3.9.5`、GitHub Pages 部署或發布後正式站 smoke。
- 正式發布完成前，V3.9.3 仍是唯一已發布版本；不得把 V3.9.5 發布候選描述為已上線。
