## 發布內容

- 地點搜尋候選照片使用 Google Place Photos，只供確認當次候選，不寫入 Trip。
- 每日行程卡片照片由管理者從 Wikimedia Commons 候選中手動選擇；壓縮為 WebP 後保存到 `itinerary-covers`。
- Commons 候選支援同一搜尋詞的「換一批」分頁；前端以 Commons `gsroffset` 取得下一批結果，換關鍵字時重置為第一批。
- 卡片沿用已核准的左圖、中間文字、右側操作緊湊橫列；照片區只占實際高度，後續說明文字會向左回流並使用完整卡片寬度；作者與授權文字上緣對齊「在地圖中查看」按鈕，原字級與左側間距不變。
- 跨日複製沿用同一照片引用；最後一個引用移除後才清除 Storage 物件。
- migration：`20260912093527_v390_itinerary_cover_storage.sql`。
- Edge Function：`travel-route`；正式部署保持 `verify_jwt=false`，由函式內 `auth.getUser()` 與 Trip 角色檢查授權。

## 停止與回復原則

- backup、migration、SQL 驗證、advisors 或 Function 部署任一失敗，停止後續前端發布。
- migration 為 additive；套用後不回寫，問題以新的向前修復 migration 處理。
- Function 部署失敗時，舊版前端不會呼叫 V3.9.0 照片 action，可先停止並修正 Function。
- 前端發布後若照片流程異常，優先停用或回退前端入口，不直接刪除 production bucket／quota table。
