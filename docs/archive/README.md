> 目前版本、發布狀態與目前開發目標，唯一以《[../14_專案現況總覽](../14_專案現況總覽.md)》為準。

## 搬遷原則

- 所有歸檔項均由原 `docs/<檔名>` 以 `git mv` 搬到下列目標，沒有刪除文件。
- 歸檔門檻是版本檔一致、`main` 合併、annotated tag、部署成功與發布後 smoke 均有可驗證證據。
- 未達門檻的版本文件留在 `docs/`，並在《[../14_專案現況總覽](../14_專案現況總覽.md)》標明待補證據。
