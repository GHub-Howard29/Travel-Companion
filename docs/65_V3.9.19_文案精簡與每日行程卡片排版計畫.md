# V3.9.19 文案精簡與每日行程卡片排版規格

> 狀態：2026-09-30 V3.9.19 已正式發布完成。已完成實作、專項靜態驗證、TypeScript、lint、完整 `npm run build`、桌面與 390×844 DevTools DOM 排版／互動驗收，以及 GitHub Pages RC2 實機／UI 驗收。正式 source commit `c5a87a3`、annotated tag `v3.9.19` 已推送；重新 build 與 RC2 `c0a42db` 的核心產物 hash 逐檔一致，公開 metadata 與 UI 均為 3.9.19。

## 目標與界線

降低介面文案密度與每日行程卡片的窄欄斷行，同時保留安全、權限、資料遺失、來源授權、錯誤復原與無障礙資訊。本版只調整文案、視覺層次與卡片排版，不調整排序後時間演算法、Google Routes 查詢或「調整時間」功能規則。

## 已定案：每日標題

1. 標題由 `Day 4 行程探索 10-06（星期二）` 精簡為 `D4 · 10/06（二）`。
2. 農曆維持原本位置，緊接在西曆後方，只保留正常文字間距，不額外預留空白。
3. 農曆與西曆使用相同字級；農曆改用較淡的次要文字色，不縮小字體。
4. `showLunarDate` 現有資料、新增／編輯旅程開關、預設值與顯示／隱藏行為全數不變。
5. 開啟農曆時的完整範例為 `D4 · 10/06（二）（八月廿六）`；關閉時不為農曆保留空白。

## 已定案：每日行程卡片

### 資訊區

1. 保留完整「到達／離開」文字、時間、類型與活動標題。
2. 有圖片時，圖片、照片來源、時間、類型與標題維持在上方資訊區。
3. Wikimedia Commons 仍在縮圖下方保留「照片來源」連結；自行上傳維持現行不顯示來源字樣。
4. 活動說明不再繞著 76×76 圖片排列；須等上方圖文資訊區結束後，由卡片左側開始以完整寬度排列。
5. 無圖卡片使用同一資訊層次，不為了對齊圖片預留空白。

### 長說明與操作列

1. 說明預設最多顯示 3 行；不超過 3 行時完整顯示，不出現「展開」。
2. 超過 3 行時才顯示「展開」；展開後顯示完整原文且按鈕改為「收合」，收合後回復 3 行。
3. 不刪除、截短或改寫使用者已儲存的行程說明資料。
4. 「展開／收合」、選配的其他資訊捷徑與「查看地圖」放在同一操作列、使用同一高度。
5. 「展開／收合」靠左；其他資訊捷徑與「查看地圖」維持靠右，其他資訊緊鄰地圖，地圖固定在最右側。
6. 未連結其他資訊時不顯示該捷徑；無地點時不顯示地圖按鈕；不為任一隱藏按鈕保留空位。
7. 若只有「展開／收合」，按鈕維持靠左；若說明不需展開，右側操作組維持靠右。
8. 地圖按鈕保留定位圖示與「查看地圖」，不回復已移除的重複聯外圖示。
9. 進入管理模式後的照片、編輯與刪除功能維持現有獨立管理操作區，不與瀏覽模式操作列混合。

## 不可因精簡而刪除

- 編輯權移除、跨裝置新版、未同步資料與版本衝突的事實、禁止編輯與復原步驟。
- 刪除旅程、縮短天數、歷史旅程管理者編輯等不可復原或會直接更新資料的警告。
- 本機個人帳本與附件在換裝置或清除瀏覽器資料後的遺失風險。
- Wikimedia Commons／自行上傳的來源、作者、授權、修改與侵權警告。
- 敏感資料可見對象、權限與儲存前確認。

## 驗收條件

### 功能與排版

1. 桌面版與 390×844 行動版均無水平溢位。
2. 開啟／關閉農曆後的標題內容正確，關閉時無多餘空白；開啟時農曆與西曆字級相同且視覺較淡。
3. 分別驗證無圖、Commons 圖片、自行上傳圖片、無說明、3 行內說明與超過 3 行說明。
4. 長說明可來回展開／收合，內容不遺失；短說明不出現多餘按鈕。
5. 分別驗證「只有展開」、「只有其他資訊」、「只有地圖」、「三者皆有」與「三者皆無」；操作列對齊且不預留隱藏空位。
6. 其他資訊捷徑、地圖、照片檢視與圖片來源連結功能均維持。

### 無障礙與文案

1. 鍵盤可聚焦並操作展開／收合、iOS 問題、其他資訊與地圖按鈕；焦點樣式可見。
2. 展開控制反映正確的 `aria-expanded`，DOM 與螢幕閱讀順序為上方資訊、說明、操作列。
3. 文字放大後不遮住標題、說明或操作按鈕；按鈕可換行但不重疊。
4. 每項定案文案均與本規格一致；安全、權限、資料遺失、授權與錯誤復原資訊沒有被刪除。

5. 本機回歸環境完整驗證後，再由 Product Owner 確認桌面與 390×844 候選版。
