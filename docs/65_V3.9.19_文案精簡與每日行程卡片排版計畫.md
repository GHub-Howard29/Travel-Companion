# V3.9.19 文案精簡與每日行程卡片排版計畫

> 狀態：2026-09-29 完成版本立案與第一輪範圍定案。尚未完成 UI 確認圖、文案全站盤點、實作或驗證；未經 Product Owner 核准 UI 確認圖不得進入實作。

## 目標

降低介面文案密度與每日行程卡片的窄欄斷行，同時保留安全、權限、資料風險、來源授權與無障礙資訊。此版本只處理文案與呈現，不調整排序後時間演算法、Google Routes 查詢或「調整時間」功能規則。

## 已定案內容

1. 每日標題由 `Day 4 行程探索 10-06（星期二）` 精簡為 `D4 · 10/06（二）`；農曆依既有設定顯示，不取消使用者控制。
2. 行程卡片保留完整「到達／離開」文字，不改成純時間範圍。
3. 時間調整模式提示改為「選擇起點，預覽後續時間」。
4. 行程管理常駐提示改為「新增依到達時間排序；編輯時間不改卡片順序。」時間格式、未填離開時間等細節移到對應欄位提示及錯誤訊息。
5. 路線資訊文案本版暫不變動。
6. 長說明預設顯示重點行數並提供「展開」，完整內容不刪除；兩行或三行須以 UI 確認圖比較後定案。
7. 有照片卡片的圖片、時間、類型與標題維持上方資訊區；照片來源留在圖片下方；說明由整個圖片區塊下方開始，以完整卡片寬度排列，不再繞著圖片形成窄欄。

## 擴大文案盤點

盤點不得只搜尋單一句文字，須以實際使用流程檢查以下畫面：

- Google 登入前的安全提示、一般瀏覽模式、登入狀態與權限提醒。
- iOS 安裝版 Google 驗證失敗的說明；必要步驟必須保留，可評估改為「iOS 登入遇到問題？」展開區。
- 每日行程新增／編輯、排序、時間調整、複製、照片與交通方式的使用說明。
- 共用／私人清單、其他資訊、旅費帳本、外幣換算與版本更新提示。
- 離線、本機保存、同步中、遠端版本衝突、撤權及重新載入等不可忽略的資料風險訊息。
- 表單欄位格式提示、驗證錯誤、成功訊息與空狀態；能貼近欄位者不放在頁首長段落。

盤點結果至少分為「可直接縮短」「改為漸進揭露」「必須完整保留」三類。安全、隱私、權限、資料遺失風險、第三方授權及錯誤復原步驟不得只為縮短而刪除。

## UI 確認圖門檻

實作前須提供同一組真實行程資料的桌面版及 390×844 行動版確認圖，至少包含：

1. `D4 · 10/06（二）` 加上農曆顯示的標題。
2. 無照片卡片，以及有照片卡片的新排列。
3. 長說明收合兩行與三行兩種方案、展開後完整內容及再次收合。
4. 行程管理精簡提示與時間預覽提示。
5. 一般登入安全提示及 iOS 特殊說明的精簡／展開方案。
6. 確認文字放大、鍵盤操作、螢幕閱讀順序及 390px 寬度無水平溢出。

Product Owner 核准確認圖後，才可把核准方案寫成完整實作與驗證清單。
