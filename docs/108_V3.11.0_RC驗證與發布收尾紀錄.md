## 1. 發布範圍

新增 TRIP 時可選擇 Excel 建立，直接建立一筆新 TRIP 及其每日行程卡片。V1 使用固定兩工作表範本：可見「新增 TRIP」與隱藏「系統設定」（`template_version=1`）。不包含既有 TRIP 卡片匯入／覆蓋。

Excel 欄位只包含 TRIP 名稱、出發日期，以及每日卡片的日序、開始時間、結束時間、行程名稱、類別與描述。天數依最大有效日序推導；不匯入地點／地址／Place ID／座標，不觸發地圖、天氣、路線或照片流程。其他 TRIP 設定由系統預設。

只有 Super Admin 可執行；提交時重新檢查登入 Session 與目前帳號，RPC 依 JWT、`auth.uid()` 及資料庫權威角色再次授權。建立以雲端整批交易為唯一成功來源；同一 request UUID 冪等、payload 不一致拒絕、交易失敗整筆 rollback。不同 request UUID 即使 title、日期及 payload 完全相同，仍代表新的建立意圖，可建立不同 TRIP。

結果不明時保留原 request UUID：建立服務先即時查詢一次，仍不明則等待 30 秒後自動查詢一次；仍無法確認時停止自動查詢，只有使用者明確接受重複風險後才以新 request UUID 再次匯入。`REFRESH_UNCONFIRMED` 不提供再次匯入。
