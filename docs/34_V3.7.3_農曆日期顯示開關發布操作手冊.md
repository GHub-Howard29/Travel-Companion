# V3.7.3 農曆日期顯示開關發布操作手冊

> 狀態：已發布；Git 標籤、GitHub Pages 與正式 metadata／資產確認均已完成
>
> 建立日期：2026-09-08
>
> 發布政策：一般更新；`minimumSupportedVersion: 3.6.4`、`forceUpdate: false`

## 發布範圍

- 新增與編輯旅程皆提供「顯示農曆日期」開關，設定以每趟旅程保存並隨既有本機／雲端 Trip 資料同步。
- Day 標題只顯示西洋月日，例如 `01-27`；開啟農曆時顯示 `01-27（臘月初九）`，關閉時不顯示括號內容。
- 舊旅程沒有此欄位時預設顯示農曆日期；農曆由已打包的前端套件離線換算，無需網路請求。換算失敗時安全降級為只顯示西洋月日。

## 發布前檢查

- `package.json`、`package-lock.json`、`src/config/appVersion.ts` 與 `public/app-version.json` 均為 `3.7.3`。
- `PREVIOUS_RELEASE_VERSION = "3.7.2"`，且 V3.7.2 已收錄在 `versionHistory.ts`。
- `npm run lint`、`npm run build`、日期／農曆專項與瀏覽器安全驗證均通過。
- 本版沒有新增套件、Supabase schema、RLS、Edge Function 或資料轉換；不需 production migration 或 backup。

## 部署後確認結果

- 已建立並推送帶註解 Git 版本標籤 `v3.7.3`。
- 正式 `app-version.json` 已確認為 `3.7.3`，首頁已引用該版 production build 資產；後續已由 V3.7.4 正常向前更新。
- 在新增／編輯旅程切換農曆顯示後，Day 標題應立即呈現或隱藏 `（農曆月日）`；離線快取中的舊資料仍預設顯示農曆。
