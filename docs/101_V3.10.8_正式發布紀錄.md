## 1. 發布範圍

- 天氣歷史快取顯示明確的歷史資料提示；到達時間或目的地日期已過時，保留終止更新狀態，避免同一地點／日期／到達時間因重新開啟、重新 render 或短暫重試而重複發出請求。
- 終止狀態以卡片、地點、預報日期及到達時間關聯；當使用者更改相關輸入時重新判斷資格。
- 天氣狀態浮動視窗與來源資訊支援點擊外部關閉。
- 最後更新時間以目的地時區的地理區域名稱呈現，例如「東京時間／台北時間」。
- 沿用既有正式資料庫 schema、migration、RLS、排程與 Secrets；本版未修改正式資料庫、migration 或 Secrets。

## 4. 上線後驗收狀態

部署 smoke 只能確認公開資產與函式部署狀態，不代表真實行程卡片的天氣端到端驗收已完成。仍請使用者在正式網站測試：

1. 一張尚有有效預報的天氣卡片：確認時間標籤顯示「東京時間／台北時間」等名稱，且最後更新時間與目的地當地時間相符。
2. 已過目的地到達時間／日期的卡片：有未超過顯示期限的快取時應顯示歷史資料提示；沒有可用快取時顯示「預報已超過有效期限，系統已停止更新天氣資料」。
3. 關閉再開啟行程、切換日期或重新 render：同一地點／日期／到達時間已進入終止狀態後，不應再次請求天氣；更改地點、日期或到達時間後，則應重新評估。
4. 開啟天氣狀態／來源資訊，再點擊視窗外：浮動視窗應關閉；沒有可顯示預報時不應呈現來源區塊。
5. 若 PWA 顯示更新提示，確認新版 Service Worker 的實際接管與頁面版本，不以單次 reload 作為更新完成證據。

目前未宣告上述人工 UI／端到端項目通過；收到使用者測試結果後再更新本紀錄。
