- `docs/sql/025_v381_trip_deletion_tombstones_validation.sql` 共 17 項全數通過：
  - tombstone 欄位、RLS、GRANT 與 trigger。
  - Guest、User、`trip_editor`、`super_admin` 均可讀最小墓碑，且不能直接寫入。
  - Browser roles 無法直接 DELETE `trips`；User 與 `trip_editor` 無法呼叫刪除成功。

  - deletion revision 與墓碑一致；零列刪除拒絕；原 ID 復活拒絕。
  - 重複墓碑造成 `unique_violation` 時，Trip 與關聯資料完整回滾。
