## 6. Production migration 與 postflight

- 2026-09-11 在專案外建立 `roles.sql`、`schema.sql` 與 `data.sql` logical backup；三份檔案皆非空並完成 SHA-256 核對。資料庫備份不包含 Storage 實體檔案。
- Codex 原執行環境找不到 Docker 的原因是 Docker Desktop 安裝於使用者目錄、`resources\bin` 未進入該 process PATH；以工作階段暫時補入實際路徑並取得沙箱外 Docker Engine 權限後，Client／Server 29.7.2 均正常，不需重裝或永久修改 PATH。
- `supabase db push --dry-run --skip-vault` 只列出 `20260910140949_v381_trip_deletion_tombstones.sql`，未包含 seed、roles 或 Vault 更新；取得 Product Owner 明確授權後正式套用成功。
- 套用後 `supabase migration list` 顯示 17 筆本機／production history 完全一致。
- 新增並執行唯讀 `docs/sql/029_v381_production_postflight.sql`；table／最小欄位、RLS、policy、GRANT、RPC 硬化、直接 DELETE 封鎖、兩個防護 trigger、revision trigger 與兩筆受保護 seed 共 10 項全數通過。
