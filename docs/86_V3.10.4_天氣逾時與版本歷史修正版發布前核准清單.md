## 1. 修正範圍

- 天氣 Edge Function 增加 Trip 讀取與單一卡片處理逾時，避免正式請求長時間沒有回應。
- 前端天氣批次逾時時保留各卡片的失敗結果與安全診斷碼，不再因單批失敗丟失整體結果。

## 2. 安全與資料邊界

- Edge Function 只記錄安全錯誤碼與 opaque trace ID，不記錄 API key、Authorization token、Trip／地點識別值或 provider 原始回應。
- 既有 Google Maps API key、Supabase service role 與其他 secrets 維持在 Supabase Edge Function secret store。
- 正式部署只包含已驗證的 Edge Function 與前端 bundle，不執行資料庫破壞性操作。
