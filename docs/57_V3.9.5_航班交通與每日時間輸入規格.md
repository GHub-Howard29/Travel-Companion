# V3.9.5 航班交通與每日時間輸入規格

## 目標

修正航班卡片仍被規劃為下一站地面交通的錯誤，並讓每日行程的到達、離開與時間調整輸入，採用與跨日複製一致的數字輸入體驗。

## 航班交通規則

- 判斷依據是區段起點卡片：只要該卡片已標示為航班，即不建立、顯示、快取或使用它到下一張卡片的地面交通。
- 儲存航班卡片時清除該卡片既有的 `travelToNext` 與 `travelModeToNext`，避免先前的地面估算殘留。
- 自動交通估算、卡片間提示、交通時間警告與「調整時間」預覽皆採同一判斷；時間調整會清楚說明航班區段不提供地面交通推算。
- 不推斷航班本身時長、機場接駁或跨日移動；這些仍由管理者以明確行程卡片輸入。

## 每日時間輸入

- 到達時間、離開時間與時間調整的新離開時間接受 `H:MM`、`HH:MM`、半形四碼與全形四碼，例如 `8:00`、`08:00`、`0800`、`０８００`。
- 完整且有效的四碼數字自動格式化為 `HH:MM`；`2400`、`2460` 等無效範圍保留原輸入並以明確錯誤提示修正方式。
- IME 組字期間不格式化；組字完成後才判斷格式。刪除已格式化的冒號時不得立即自動補回，避免游標跳動。
- 儲存前統一正規化為 `HH:MM`，並保持同日離開時間不得早於到達時間的既有規則。

## 驗證與發布邊界

- 本版需以純函式／靜態契約、型別、lint 與 production build 驗證；互動式瀏覽器與本機 Supabase 回歸另依當次授權執行。
- 不含資料庫 migration、production、版本 metadata、commit、push 或部署。
