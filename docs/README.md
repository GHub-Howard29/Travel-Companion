# Travel Companion 文件入口

Travel Companion 是以 Trip 為核心的 Offline First 旅行管理 PWA，使用 React、TypeScript、Vite 與 Supabase，支援行程、清單、資訊、多人帳本、附件及外幣換算。

> 已發布版本：V3.6.0
>
> 已完成資料庫維護：V3.5.2（無獨立 App build／tag）
>
> 最新發布：V3.6.0「地點間預估移動資訊」（2026-08-30；正式 Supabase、Google Cloud 與 GitHub Pages 已部署驗證）
>
> 下一版 V3.7.0「當日後續行程時間連動調整」已於 2026-08-31 完成開發內容、細節與互動模擬定案，可進入實作。
>
> 最後更新：2026-08-31
