## 文件搬遷規則

- 只有檔名明確包含產品版本號，且該版本已正式發布並符合歸檔門檻的版本專屬文件，才搬至 archive。
- 沒有產品版本號的文件一律不因「看起來舊」而自動搬遷；先列入《[文件歸類待討論](文件歸類待討論.md)》，確認用途與分類後再決定。
- 草案、未發布版本、仍在追蹤的診斷與待驗收文件，不因檔名含版本號就自動歸檔；必須核對發布狀態與未結事項。
- archive 不是日常開發的預設必讀範圍；追溯特定版本、問題或發布證據時再按需閱讀。
