# Travel Companion 文件入口

Travel Companion 是以 Trip 為核心的 Offline First 旅行管理 PWA，使用 React、TypeScript、Vite 與 Supabase。

> 目前部署版本、正式發布狀態與下一個開發目標，唯一以《[14_專案現況總覽](14_專案現況總覽.md)》為準。
