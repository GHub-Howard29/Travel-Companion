## Production-safe smoke

- OPTIONS 回應 200，CORS 允許 POST／OPTIONS 與本 App 必要標頭。
- 正確 JSON 但缺少 `tripId` 回應 400「缺少旅程識別資訊」。
- 帶有合成字串 `tripId` 但未登入回應 403「只有本行程管理者可以查詢地圖服務」。
- 第一輪 curl 因 PowerShell 引號破壞 JSON，得到 500 泛用錯誤；該結果不列為產品驗收，修正引號後重新執行上述 400／403 並通過。
- smoke 全程未提供正式使用者憑證、未觸發 Wikimedia、未寫入 Storage／Trip。Postflight 確認 `commons_precision_cache` 與 `commons_precision_usage_daily` 仍為 0；quota 與 upstream lock 只保留各 1 筆初始化 singleton。

## 發布候選驗證

- `npm run regression:local:full` 通過：本機 grants、管理者登入、Trip 載入、Edge 輸入防線及 V3.9.1 整合契約通過，未送出 Wikimedia 請求。
- `npm run lint` 通過。ESLint 新增忽略 `supabase/.temp/**`，避免掃描 Supabase CLI 產生的一行式 bundle；專案原始 TypeScript／TSX 規則不變。
- `npm run build` 以版本 `3.9.1` 通過全部契約、版本歷史／更新政策、TypeScript、Vite production build、PWA precache 與瀏覽器安全檢查。
- Codex 內建瀏覽器通過桌面與 390×844：照片來源、預填詞、單字搜尋禁用、候選確認按鈕、Escape 關閉與焦點返回。
- loopback-only 同名實體 fixture 通過 3 個全寬選項：短描述、多行描述、無描述；三者均顯示 QID 且讀屏名稱完整。選定後顯示「搜尋範圍：中山站」並固定以 `no-suitable-image` 結束。
- 390×844 下 `innerWidth`、document client width 與 scroll width 均為 390；dialog 為 12–378px，沒有水平溢位。測試後已清除 viewport override。
