# V3.10.7 天氣目的地當地時間判斷修正與結案紀錄

> 狀態：V3.10.7 正式發布已完成並結案；台灣、日本正式網站實際行程測試均由使用者確認通過，正式 source、tag、GitHub Pages 與公開 smoke 證據均已核對。
> 整理日期：2026-10-20

## 1. 結案範圍

V3.10.7 天氣預報資格判斷以景點目的地當地日期與時間為準，不再將伺服器 UTC 日期或尚未成功預報的初始 `UTC` 值當成目的地時區。修正範圍包含前端回應合併、Edge Function 的資格判斷，以及專用回歸測試。

- 有成功預報的快取時，使用快取中的目的地 IANA 時區（例如 `Asia/Tokyo`）判斷行程日期與到達時間。
- 沒有可信的成功預報時區時，先向 Open-Meteo 取得座標對應的目的地時區，再作資格判斷；不把初始占位值 `UTC` 視為權威時區。
- 背景掃描以相鄰 UTC 日期作保守候選範圍，最終仍由目的地當地日期規則決定是否可預報。
- 若目的地當地到達時間已過，停止刷新並顯示仍有效的上次成功資料；沒有可用快取時回傳明確的不符合資格狀態。
- 前端請求指紋納入卡片時間；沒有任何可請求的天氣目標時不發送空請求。
