## 停止與回復原則

- backup、migration、SQL 驗證、advisors 或 Function 部署任一失敗，停止後續前端發布。
- migration 為 additive；套用後不回寫，問題以新的向前修復 migration 處理。
- Function 部署失敗時，舊版前端不會呼叫 V3.9.0 照片 action，可先停止並修正 Function。
- 前端發布後若照片流程異常，優先停用或回退前端入口，不直接刪除 production bucket／quota table。
