## 目前能力

- 以 Trip 為核心，提供每日行程、共同／私人清單、其他資訊、多人旅費帳本、附件、Excel 匯出及外幣換算。
- React／TypeScript／Vite PWA，非首屏 Travel Tool 與 Excel 採按需載入。
- 使用 localStorage、IndexedDB 與 Supabase 實作 Offline First、雲端同步及附件管理。
- 角色包含 Guest、User、`trip_editor`、`super_admin`；目前權限矩陣見《13_權限設定資料表》。
- PWA 具版本更新提示；一般更新可稍後，強制更新不可稍後。

## 最新資料庫維護：V3.5.2（無獨立 App 發布）

- 已建立向前 migration，將兩個 `SECURITY DEFINER` 權限查詢核心移至非暴露 `private` schema，`public` 同名函式改為 `SECURITY INVOKER` 相容包裝。
- 正式資料庫共有 13 個 `tc_` 公開函式；migration 已將其全部固定為空 `search_path`，撤銷 `PUBLIC` 隱含執行與 trigger-only API 執行權，並設定未來函式預設拒絕公開執行。

- migration 已正式套用（Supabase migration `20260826083326`）；13 個公開函式的 catalog 驗證、核心角色／RLS 16 項與 Storage 13 項回歸全部通過，fixture 均已 `ROLLBACK`。
- 套用後 advisors 已確認本版原有的 5 個 mutable `search_path` 與 4 個公開 `SECURITY DEFINER` 警告全部清除；剩餘 Auth 密碼保護與 checklist 效能／索引建議不屬本版範圍。
