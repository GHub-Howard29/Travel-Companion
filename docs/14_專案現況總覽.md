## 目前能力

- 以 Trip 為核心，提供每日行程、共同／私人清單、其他資訊、多人旅費帳本、附件、Excel 匯出及外幣換算。
- React／TypeScript／Vite PWA，非首屏 Travel Tool 與 Excel 採按需載入。
- 使用 localStorage、IndexedDB 與 Supabase 實作 Offline First、雲端同步及附件管理。
- 角色包含 Guest、User、`trip_editor`、`super_admin`；目前權限矩陣見《13_權限設定資料表》。
- PWA 具版本更新提示；一般更新可稍後，強制更新不可稍後。

## 最新發布：V3.4.9

- 已修正共同清單初始同步舊快照覆蓋首次勾選，以及連續寫入可能失序的問題。
- 歷史行程離線時顯示明確唯讀提示，尚未結束與未來行程維持原有離線規則。
- Android 原生 Splash 顯示 PWA 圖示；網頁載入階段只保留一致藍底，等首個功能頁完成後才切入操作介面，避免第二次圖示跳動。
- `v3.4.9` tag 與既有 GitHub Pages 部署版本均為 V3.4.9；載入畫面發布後調整待部署與 Android PWA 實機複驗。
- 本版沒有 Supabase schema、RLS、migration 或 Trip 隱私變更，`FORCE_UPDATE = false`。

## 下一個功能版本：V3.5.0

- 新增 Trip 公開／私人設定與 Guest 存取模型。
- UI、`is_public` migration、RLS、REST、靜態 Trip 移除及帳號隔離快取必須同版發布。
- 既有與新建 Trip 預設私人；只有 `super_admin` 可切換公開狀態。
- 目前建議 `FORCE_UPDATE = true`，發布前最終確認。
- 正式 migration 前必須備份、隔離演練並完成多角色與直接網址驗證。
