## 已完成功能

- 已完成目前程式碼的 ESLint、TypeScript 與 production build 驗證。
- 初始 JavaScript bundle 已由 1,571.41 kB 降至 489.70 kB；非首屏旅行工具與 Excel 匯出套件採按需載入。
- production PWA 已通過 service worker precache、離線重載與旅行工具切換驗證。
- Product Owner 已在本機確認 Service Worker 註冊與控制、PWA precache、旅行工具動態載入與切換、Excel 匯出及更新提示顯示。

### 旅程與導覽

- Trip 建立、編輯、刪除與可編輯者管理。
- 每日行程依活動時間由早到晚顯示；未填時間的活動置底。
- 開啟旅程時，依出發日期自動選取對應 Day；旅程外期間預設 Day 1。
- 已登入使用者可將任一工具設為個人預設首頁；GUEST 不顯示此功能。
- 側欄工具圖示使用海水藍色，並提供預設首頁星號說明。

### 檢查清單

- 共同檢查清單：管理者可新增、編輯、刪除、勾選與排序；項目與分類根目錄皆可排序，並同步雲端。
- 一般登入使用者可自行創建及使用在本機設備上的共同檢查清單。
- 私人確認清單以 `userEmail + tripId` 隔離；已勾選項目自動置底，跨裝置時以最後更新的本機或雲端資料為準。
- 可排序卡片（共同清單、私人清單、領隊／導遊聯絡資訊、其他資訊）支援拖拉與上下箭頭；排序先更新畫面，再延後同步。
- 私人與共同清單的 USER 模式不顯示雲端複製與同步提示。

### 參考資訊與旅行工具

- 領隊／導遊聯絡資訊與其他資訊可瀏覽、管理、排序並雲端同步。
- 旅費記帳本支援多人帳本、附件、日期、分攤與 Excel 匯出；混合幣別總覽統一以「幣別代碼＋符號＋金額」的緊密格式顯示支出合計，匯出入口位於帳本明細最下方。
- 新增旅費時，若登入 Email 對應付款人，系統會鎖定且僅以橘色底標示該付款人。
- `super_admin` 匯出共用帳本時，會下載目前旅程所有雲端明細，包含其他管理員與 `trip_editor` 建立的紀錄。
- 帳本 XLSX 會以獨立的「支出人幣別合計」工作表，呈現支出人＋幣別的金額合計與明細筆數；原始明細不混入此工作表。
- 帳本 XLSX 先依支出人排序，同一支出人內依幣別明細筆數由多到少排序，筆數相同才以幣別代碼排序。
- 帳本 XLSX 的記帳日期欄固定以完整的 `YYYY-MM-DD` 格式輸出。
- 外幣換算支援換匯紀錄、加權平均、臺銀參考匯率與本機離線參考資料。
- 版本資訊可由所有角色查看；目前版本不會重複出現在版本歷史。

### 權限與資料

- 角色為 GUEST、USER、trip_editor、super_admin；完整矩陣見 [權限設定資料表](13_權限設定資料表.md)。
- Trip、共同清單、私人清單、其他資訊與帳本已具 Supabase 雲端資料與權限控制；本機資料作為相容與離線備援。
