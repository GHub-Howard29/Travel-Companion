## 正式版本

- 已發布 App 版本：V3.9.0；`main`、帶註解標籤 `v3.9.0`、GitHub Pages、正式 metadata、Service Worker、版本資訊與 Guest smoke 均已完成發布驗證。

## 目前能力

- 以 Trip 為核心，提供每日行程、共同／私人清單、其他資訊、多人旅費帳本、附件、Excel 匯出及外幣換算。
- 每日行程支援到達／離開時間、相鄰地點交通方式／時間／距離、Google Maps 外部開啟，以及 V3.7.0 單次後續時間調整。
- React／TypeScript／Vite PWA；使用 localStorage、IndexedDB 與 Supabase 實作 Offline First、雲端同步及附件管理。
- 角色包含 Guest、User、`trip_editor`、`super_admin`；權限矩陣以《13_權限設定資料表》為準。
- Trip 主資料寫入使用遠端版本檢查，跨裝置版本衝突時不覆蓋遠端資料。

## 最新發布能力

- 地點搜尋候選會顯示 Google Place Photos 索引照、地址及地圖連結，只供當次地點確認，不寫入 Trip。
- 每日行程管理者可搜尋、換批並選用 Wikimedia Commons 照片；保存 WebP 與來源、作者、授權資訊，跨日複製沿用同一引用。
- 每日卡片照片只占實際高度，後續說明向左回流；作者／授權文字與地圖按鈕上緣對齊。桌面與 390×844 正式站驗證通過。
- 跨日複製開啟時顯示來源抵達／離開時間，但新副本時間預設空白且兩欄必填；支援半形／全形冒號並正規化為 `HH:MM`。
- 一次選擇多個目標 Day 時共用同一組新時間，每份副本建立獨立 ID 並依新抵達時間穩定插入；相同時間放在既有同時段卡片之後。
- 目標 Day 既有卡片不重新排序；插入點前一張卡片若改變目的地，只清除 `travelToNext` 並保留交通方式偏好。
- 多個 Day 以一次 Trip 寫入，失敗或遠端版本衝突時不產生部分副本；成功後留在來源 Day。
- V3.8.2 已完成領域測試、TypeScript、lint、完整 build、桌面／390×844 驗證與正式站版本資訊 smoke；發布結果見《43_V3.8.2_正式發布操作手冊》。

## V3.9.1 停止線前進度計畫

目前已完成的範圍是「本機可重建、後端契約與前端實作」；尚未宣稱可發布。後續依下列順序收斂：

1. **本機互動驗收**：使用登入管理者，在桌面與 390×844 完成唯一範圍直接搜尋、多實體選擇、設施級安全停止、換一批、候選確認、手動裁切、放大檢視、鍵盤與焦點陷阱驗收。
2. **本機整合回歸**：以本機 Edge Function 實際請求驗證授權、`entity-ambiguous` 選擇後續作業、續頁 token、快取／配額／鎖與錯誤狀態；不使用正式資料、不觸發正式 Wikimedia 額度。
3. **正式環境閘門**：另案核准後才套用 production migration／secrets、部署 Edge Function，並執行 production-safe smoke、RLS／advisors 與正式前端互動驗收。
4. **發布準備**：依核准結果更新 metadata、版本紀錄與發布文件，完成 release build、tag／部署與發布後 smoke；在此以前不得合併 `main` 或宣稱 V3.9.1 已發布。

本次修正補入 `supabase/migrations/20260710100000_restore_legacy_schema_prerequisites.sql`，只負責重建歷史上未納入 migration 的本機前置結構；未回寫既有 migration，未連線或修改正式 Supabase。

## 開發與發布邊界

- 所有新增或調整畫面必須先提供模擬圖，經 Product Owner 確認後才能修改程式。
- 未經 Product Owner 明確要求，不執行正式 Supabase migration、部署、合併、推送或建立 tag。
- 已發布 migration、版本 metadata、版本歷史與 Git tag 不回寫；問題一律以新版本向前修復。
- 修改完成後至少執行與風險相稱的純函式測試、TypeScript、lint、完整 build 與必要實機回歸。
