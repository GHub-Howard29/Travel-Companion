# 版本更新紀錄

> 本文件只記錄已發布版本的目的與摘要；詳細修改以 Git tag／commit 及 App 內 `versionHistory.ts` 為準。
>
> 最後更新：2026-08-25

## 版本規則

- Major：產品世代或大規模不相容變更。
- Minor：主要新功能或新的產品功能階段。
- Patch：Bug 修正、維護、安全、效能及小型體驗改善。
- 強制更新是獨立發布設定，不由 Major／Minor／Patch 自動決定。
