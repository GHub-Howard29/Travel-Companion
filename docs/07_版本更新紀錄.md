# 版本更新紀錄

> 本文件只記錄已發布版本的目的與摘要；詳細修改以 Git 版本標籤／commit 及 App 內 `versionHistory.ts` 為準。
>
> 最後更新：2026-09-01

## 版本規則

- Major：產品世代或大規模不相容變更。
- Minor：主要新功能或新的產品功能階段。
- Patch：Bug 修正、維護、安全、效能及小型體驗改善。
- 強制更新是獨立發布設定，不由 Major／Minor／Patch 自動決定。
- V3.5.6 起，最低支援版本由公開 metadata 的 `minimumSupportedVersion` 決定；橋接期間仍保留 `forceUpdate: true`，使不認識新欄位的歷史 App 不會略過必要更新。實作與發布前驗證見《20_V3.5.6_版本更新最低支援版本機制》。
