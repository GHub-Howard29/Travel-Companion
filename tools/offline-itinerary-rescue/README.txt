Travel Companion 完整資料離線救援工具
====================================

用途：
  從已安裝 PWA 的 Chrome／Edge 本機資料中，唯讀匯出
  「英鈦日本九州極上五日」在 Local Storage 可取得的完整目標旅程資料。

匯出內容：
  - 完整 Trip 記錄（每日行程、地圖定位、交通、照片欄位、旅程設定與參與者設定）
  - 其他資訊、子分類資料夾、共用／個人／私人清單
  - 匯率紀錄、共用與個人帳本快取、該旅程的離線帳本佇列
  - 尚未同步狀態與權限快取的鑑識資訊（不可直接匯入）

操作：
  1. 先將本工具資料夾或 ZIP 複製到 USB／Dropbox。
  2. 在可能仍保有正確資料的電腦上中斷網路。
  3. 完全關閉 PWA、Chrome 與 Edge；必要時到工作管理員確認。
  4. 解壓縮完整資料夾，不要只取出 CMD 檔。
  5. 雙擊「START-RESCUE.cmd」。
  6. 看到提示後輸入 EXPORT。
  7. 保存新產生的「救援匯出_...」資料夾。

安全邊界：
  - 工具不包含 Supabase、Dropbox 或其他網路連線功能。
  - 工具不會開啟 PWA，也不會修改瀏覽器使用者設定檔。
  - 工具只在系統暫存資料夾建立 LevelDB 副本，解析完成即刪除。
  - 匯出檔只包含目標 Trip 的 Local Storage 資料與必要驗證資訊，不包含登入權杖。
  - 不會匯出其他 Trip、auth_／sb-／supabase. 登入工作階段資料。
  - 未同步的帳本附件檔案存放在 IndexedDB，附件二進位檔不在本工具範圍；
    匯出仍會保留帳目中的附件名稱、狀態與關聯 ID 以利後續鑑識。
  - 匯出 JSON 可能包含行程、帳本、清單與 Email 等私人資料；請加密保存，勿傳給未授權者。
  - 若資料已被舊雲端內容覆蓋，工具無法重建已不存在的版本。

請勿直接編輯匯出 JSON。後續應先比較摘要與 SHA-256，再透過受控匯入流程復原。
本版本只提供匯出，不提供匯入或任何雲端寫入功能。
