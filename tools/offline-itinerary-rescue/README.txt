Travel Companion 每日行程離線救援工具
========================================

用途：
  從已安裝 PWA 的 Chrome／Edge 本機資料中，唯讀匯出
  「英鈦日本九州極上五日」的 daysData。

操作：
  1. 先將本工具資料夾或 ZIP 複製到 USB／Dropbox。
  2. 在可能仍保有正確資料的電腦上中斷網路。
  3. 完全關閉 PWA、Chrome 與 Edge；必要時到工作管理員確認。
  4. 解壓縮完整資料夾，不要只取出 CMD 檔。
  5. 雙擊「START-RESCUE.cmd」。
  6. 看到提示後輸入 EXPORT。
  7. 保存新產生的「救援匯出_...」資料夾。

安全邊界：
  - 工具不包含 Supabase、Dropbox 或其他網路連線功能。
  - 工具不會開啟 PWA，也不會修改瀏覽器使用者設定檔。
  - 工具只在系統暫存資料夾建立 LevelDB 副本，解析完成即刪除。
  - 匯出檔只包含目標 Trip 的每日行程與必要驗證資訊，不包含登入權杖。
  - 若資料已被舊雲端內容覆蓋，工具無法重建已不存在的版本。

請勿直接編輯匯出 JSON。後續應先比較摘要與 SHA-256，再透過受控匯入流程復原。
